# spine-godot-builds

Prebuilt spine-godot editor and export templates for Godot 4.x. The builds come from the
`Mimyr-Games-LTD/spine-runtimes` fork, workflow `spine-godot-v4.yml`.

## Layout

- `releases/<tag>/`: manifest of one build (`README.md` with source commit, build run and asset links; `SHA256SUMS`).
- The binaries are attached to the GitHub Release with the same tag (`spine-<spine>-godot-<godot>-stable`).

## Download

`https://github.com/Mimyr-Games-LTD/spine-godot-builds/releases/download/<tag>/<asset>`

Example: `https://github.com/Mimyr-Games-LTD/spine-godot-builds/releases/download/spine-4.2-godot-4.7.2-stable/godot-editor-linux.zip`
